# GitHub Enterprise Server on Microsoft Azure

## Welcome

Welcome to the **GitHub Enterprise Server on Microsoft Azure** training course.

This course provides a practical introduction to enterprise source control, cloud infrastructure deployment, and modern DevOps workflows.

Rather than learning Git commands in isolation, you will follow a realistic engineering project where you deploy GitHub Enterprise Server, configure it, and use it to manage real engineering content.

---

## Course Scenario

You have joined a Cloud Engineering team responsible for implementing a new internal source control platform.

The organisation requires a secure, enterprise Git solution hosted in Microsoft Azure.

Your task is to:

- Deploy the Azure infrastructure
- Install GitHub Enterprise Server
- Configure users and organisations
- Create repositories
- Manage code using Git
- Implement automation workflows

---

## What You Will Learn

By completing this course you will learn:

- The fundamentals of version control
- How Git works
- How GitHub Enterprise Server operates
- How to deploy cloud infrastructure
- How engineers collaborate using Git
- How to use branches and Pull Requests
- How automation integrates with source control

---

## Target Audience

This course is designed for:

- Cloud Engineers
- DevOps Engineers
- Platform Engineers
- Linux Administrators
- Infrastructure Engineers
- IT professionals learning modern engineering practices

## Course Structure

The course follows a complete enterprise deployment journey:
