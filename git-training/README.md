# GitHub Enterprise Server on Microsoft Azure Training

A practical, project-based training course covering Git, GitHub Enterprise Server, and Microsoft Azure.

This course teaches Git through a real-world enterprise deployment scenario. Students will deploy GitHub Enterprise Server into Azure, configure the platform, and use Git workflows to manage engineering projects.

## Course Overview

In this course you will take the role of a Cloud Engineer responsible for deploying and managing an enterprise source control platform.

The project covers:

- Microsoft Azure infrastructure
- Linux virtual machines
- GitHub Enterprise Server deployment
- Git repository management
- SSH authentication
- Branching strategies
- Pull Requests
- GitHub Actions
- Enterprise security practices
- Backup and operational management

## Learning Objectives

By completing this course you will understand:

- How distributed version control works
- How Git is used in professional engineering teams
- How to deploy GitHub Enterprise Server
- How developers collaborate using Git workflows
- How automation integrates with source control

## Technologies Covered

- Git
- GitHub Enterprise Server
- Microsoft Azure
- Linux
- SSH
- Markdown
- CI/CD Pipelines
- GitHub Actions

## Project Scenario

A company has decided to deploy GitHub Enterprise Server in Microsoft Azure.

As the Cloud Engineer, you are responsible for:

1. Building the Azure environment
2. Deploying GitHub Enterprise Server
3. Configuring access and security
4. Creating repositories
5. Supporting engineering teams using Git workflows
6. Automating documentation deployment

This course follows that complete journey.
