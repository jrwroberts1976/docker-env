    Lesson 05 - Package Management Administration Lab

    Estimated time: 90–120 minutes

    Prerequisites: - Module 05 – Package Management - Lesson 01 – Understanding Linux Package Managers - Lesson 02 – Installing Software Packages - Lesson 03 – Updating Linux Systems - Lesson 04 – Software Repositories

    Difficulty: Intermediate

    Hands-on exercises: Yes

    Overview

    This practical lab combines the skills learned throughout the Package Management module.

    You will perform common Linux administration tasks including:

    • Identifying the package manager
    • Searching for software
    • Installing applications
    • Checking installed packages
    • Removing software
    • Updating the system
    • Reviewing package information
    • Troubleshooting package problems

    The tasks simulate activities performed by Linux system administrators.

    Lab Environment

    You can complete this lab using:

    • Linux server
    • Virtual machine
    • Raspberry Pi
    • Cloud Linux instance

    Recommended distributions:

    • Debian
    • Ubuntu Server
    • Rocky Linux

    Task 1 - Identify Your Linux Distribution

    Objective

    Identify the operating system and available package management tools.

    Run:

    cat /etc/os-release

    Record:

    Distribution:

Version:

Package manager:

    Task 2 - Identify Package Manager

    Debian / Ubuntu

    Check:

    which apt

    Expected:

    /usr/bin/apt

    Red Hat / Rocky Linux

    Check:

    which dnf

    Expected:

    /usr/bin/dnf

    Task 3 - Search for Software Packages

    Objective

    Find available software packages.

    Search for nginx:

    Debian / Ubuntu:

    apt search nginx

    Red Hat / Rocky:

    dnf search nginx

    Record:

    Package found:

Description:

    Task 4 - View Package Information

    Objective

    Review package details before installation.

    Debian / Ubuntu:

    apt show nginx

    Red Hat / Rocky:

    dnf info nginx

    Record:

    Package version:

Dependencies:

Description:

    Task 5 - Install Software

    Objective

    Install a software package.

    Install nginx:

    Debian / Ubuntu:

    sudo apt install nginx

    Red Hat / Rocky:

    sudo dnf install nginx

    Verify installation:

    Debian / Ubuntu:

    dpkg -l | grep nginx

    Red Hat / Rocky:

    rpm -qa | grep nginx

    Record:

    Installation successful:

Version installed:

    Task 6 - Check Installed Packages

    Objective

    Understand installed software management.

    Debian / Ubuntu:

    dpkg -l

    Red Hat / Rocky:

    rpm -qa

    Find:

    • Installed applications
    • Package versions
    • Package status

    Task 7 - Remove Software

    Objective

    Safely remove installed software.

    Remove nginx:

    Debian / Ubuntu:

    sudo apt remove nginx

    Red Hat / Rocky:

    sudo dnf remove nginx

    Verify removal:

    dpkg -l | grep nginx

    or:

    rpm -qa | grep nginx

    Record:

    Package removed:

    Task 8 - Update Repository Information

    Objective

    Refresh available package information.

    Debian / Ubuntu:

    sudo apt update

    Review:

    • Repository connections
    • Available updates
    • Package information

    Task 9 - Update Installed Software

    Objective

    Apply available updates.

    Debian / Ubuntu:

    sudo apt upgrade

    Red Hat / Rocky:

    sudo dnf upgrade

    Record:

    Packages updated:

Reboot required:

    Task 10 - Review Package History

    Objective

    Investigate package changes.

    Debian / Ubuntu:

    cat /var/log/apt/history.log

    Red Hat / Rocky:

    dnf history

    Identify:

    • Installed packages
    • Removed packages
    • Updates performed

    Task 11 - Repository Investigation

    Objective

    Review configured software sources.

    Debian / Ubuntu:

    cat /etc/apt/sources.list

    Red Hat / Rocky:

    dnf repolist

    Record:

    Configured repositories:

    Troubleshooting Scenario

    Scenario

    A user reports:

    "The application cannot be installed because the package cannot be found."

    Investigate the issue.

    Step 1 - Check Repository Information

    Run:

    sudo apt update

    Check for:

    • Repository errors
    • Connection failures
    • Missing sources

    Step 2 - Search for the Package

    Example:

    apt search application_name

    Confirm:

    • Package name
    • Package availability

    Step 3 - Check Package Manager Status

    Check for running package processes:

    ps aux | grep apt

    Step 4 - Repair Package Problems

    If required:

    sudo apt --fix-broken install
