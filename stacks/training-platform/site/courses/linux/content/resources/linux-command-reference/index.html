    Linux Command Reference

    A quick reference guide for common Linux commands used throughout the training course.

    This document is designed as a companion reference and does not replace the individual lessons.

    Navigation Commands

    pwd - Print Working Directory

    Shows your current location.

    pwd

    Example:

    /home/james/projects

    ls - List Files

    Displays files and directories.

    Basic usage:

    ls

    Detailed listing:

    ls -l

    Show hidden files:

    ls -a

    Human-readable sizes:

    ls -lh

    Common combination:

    ls -lah

    cd - Change Directory

    Move between directories.

    Go to home directory:

    cd

    Go to a specific directory:

    cd /etc

    Move up one level:

    cd ..

    Return to previous directory:

    cd -

    File and Directory Management

    mkdir - Create Directory

    Create a directory:

    mkdir directory-name

    Create nested directories:

    mkdir -p projects/linux/module01

    touch - Create Empty File

    Create a file:

    touch notes.txt

    Create multiple files:

    touch file1.txt file2.txt

    cp - Copy Files

    Copy a file:

    cp source.txt destination.txt

    Copy directories:

    cp -r directory backup-directory

    mv - Move or Rename

    Move a file:

    mv file.txt /tmp/

    Rename a file:

    mv oldname.txt newname.txt

    rm - Remove Files

    Remove a file:

    rm file.txt

    Remove a directory:

    rm -r directory

    Force removal:

    rm -rf directory

    ⚠️ Use rm -rf carefully.

    rmdir - Remove Empty Directory

    rmdir directory-name

    Viewing Files

    cat

    Display file contents:

    cat filename

    less

    View large files page by page:

    less logfile.txt

    Useful keys:

    q       Quit
space   Next page
/word   Search

    head

    Display first lines:

    head file.txt

    Specify number of lines:

    head -n 20 file.txt

    tail

    Display last lines:

    tail logfile.txt

    Follow live changes:

    tail -f logfile.log

    Commonly used for log monitoring.

    Searching

    find

    Search the filesystem.

    Find by name:

    find /home -name "*.txt"

    Find files:

    find . -type f

    Find directories:

    find . -type d

    locate

    Fast file searching.

    locate filename

    Update database:

    sudo updatedb

    grep

    Search inside files.

    Example:

    grep error logfile.txt

    Recursive search:

    grep -r "error" /var/log

    Permissions

    chmod

    Change permissions.

    Make a script executable:

    chmod +x script.sh

    Numeric permissions:

    chmod 755 script.sh

    chown

    Change ownership.

    Example:

    sudo chown james file.txt

    Change owner and group:

    sudo chown james:developers file.txt

    Users and Groups

    whoami

    Show current user:

    whoami

    who

    Show logged-in users:

    who

    id

    Show user information:

    id

    useradd

    Create user:

    sudo useradd username

    passwd

    Set password:

    sudo passwd username

    groupadd

    Create group:

    sudo groupadd developers

    Processes

    ps

    Display processes:

    ps

    Detailed view:

    ps aux

    top

    Live process monitoring:

    top

    systemctl

    Manage services.

    Check service:

    systemctl status ssh

    Start service:

    sudo systemctl start service-name

    Enable at boot:

    sudo systemctl enable service-name

    journalctl

    View system logs.

    View logs:

    journalctl

    Follow live logs:

    journalctl -f

    View service logs:

    journalctl -u ssh

    Networking

    ip

    View network information:

    ip addr

    View routes:

    ip route

    ping

    Test connectivity:

    ping google.com

    curl

    Test HTTP services:

    curl https://example.com

    ssh

    Remote login:

    ssh username@server

    ss

    View network connections:

    ss -tulpn

    Storage

    df

    Display filesystem usage:

    df -h

    du

    Display directory usage:

    du -sh directory

    lsblk

    Display disks:

    lsblk

    mount

    Display mounted filesystems:

    mount

    Package Management

    Debian / Ubuntu

    Update packages:

    sudo apt update

    Install software:

    sudo apt install package-name

    Remove software:

    sudo apt remove package-name

    Red Hat / Rocky Linux

    Install software:

    sudo dnf install package-name

    Update system:

    sudo dnf update

    Shell and Environment

    echo

    Display text:

    echo "Hello Linux"

    Display variables:

    echo $PATH

    history

    Show previous commands:

    history

    which

    Locate commands:

    which ls

    man

    Display manual pages:

    man command

    Example:

    man ls

    System Information

    uname

    Kernel information:

    uname -r

    Full information:

    uname -a

    hostname

    Display hostname:

    hostname

    free

    Memory usage:

    free -h

    uptime

    System uptime:

    uptime

    Keyboard Shortcuts

    Shortcut Description
    Ctrl + C Cancel command
    Ctrl + L Clear terminal
    Ctrl + D Logout
    Tab Auto-complete
    ↑ Previous command
    ↓ Next command

    Useful Linux Directories

    Directory Purpose
    / Root filesystem
    /home User files
    /etc Configuration files
    /var Logs and changing data
    /tmp Temporary files
    /usr Applications and utilities
    /bin Essential commands
    /opt Optional software
