    Module 03 - Users and Groups

    Estimated time: 3–4 hours

    Prerequisites: - Module 00 – Introduction to Linux - Module 01 – Command Line Fundamentals - Module 02 – Linux Filesystem Administration

    Difficulty: Beginner to Intermediate

    Hands-on exercises: Yes

    Overview

    Linux is a multi-user operating system, making user and group management one of the most important skills for any Linux administrator.

    In this module you will learn how Linux manages user accounts, groups, passwords and administrative privileges. You'll also learn how to safely create, modify and remove accounts, assign permissions through group membership, and use sudo to perform administrative tasks securely.

    These skills are essential whether you are managing a single Linux workstation or thousands of cloud servers.

    Learning Objectives

    By completing this module you will be able to:

    • Understand Linux user and group concepts
    • Create and manage user accounts
    • Create and manage groups
    • Modify user properties
    • Manage passwords
    • Understand system and service accounts
    • Configure and use sudo
    • Troubleshoot common account and permission issues
