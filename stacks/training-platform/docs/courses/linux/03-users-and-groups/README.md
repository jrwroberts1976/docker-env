# Overview

Linux is a multi-user operating system, making user and group management one of the most important skills for any Linux administrator.

In this module you will learn how Linux manages user accounts, groups, passwords and administrative privileges. You'll also learn how to safely create, modify and remove accounts, assign permissions through group membership, and use `sudo` to perform administrative tasks securely.

These skills are essential whether you are managing a single Linux workstation or thousands of cloud servers.
