# Kubernetes Administration Training

## Course Status

🚧 **Planned / In Development**

# Course Overview

This training course will introduce Kubernetes concepts and provide hands-on experience building, deploying, and operating Kubernetes environments.

The course will focus on practical engineering skills used in modern DevOps and Platform Engineering roles.
