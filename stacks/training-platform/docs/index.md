## CI/CD Automation

Building automated pipelines where changes are:

1. Committed to Git
2. Tested automatically
3. Built into container images
4. Published
5. Deployed automatically

Example workflow:

```
Developer Change
        |
        v
Git Push
        |
        v
GitHub Actions
        |
        v
Docker Image Build
        |
        v
Container Registry
        |
        v
Automated Deployment
```
